→
在 N 次内，凑齐最后 ¥1

达标到账 ¥100；次数用尽未达标，到账 ¥0。

先认识这几个变量

p · 每刀有效的概率

由你设定的模型条件。12% 表示大量邀请中，平均约 12% 能增加金额；不保证每 100 次恰好成功 12 次。

δ · 有效时增加多少钱

仅在有效助力时增加金额。比如每次增加 ¥0.10，就需要 10 次有效助力。

N · 一局最多邀请几次

这是邀请预算，不是模拟局数。包含有效和无效邀请；达标后会提前停止。

M · 模拟多少个独立玩家

对应下方“批量实验次数”。M 越大，模拟成功率通常越稳定；它不改变单个玩家的理论成功概率。

K、r · 有效次数与门槛

K 是 N 次邀请中有效的次数，是随机变量；r = ⌈1/δ⌉ 是凑齐 ¥1 至少需要的有效次数，向上取整。

q、X · 最终要研究的结果

q 是一局达标的概率，取决于 p、δ、N；X 是实际到账金额，只可能为 ¥0 或 ¥100。p 和 q 不是同一个概率。

03 / 从实验到公式

进度条之外，数学说了什么？

01

把规则说清楚

已完成 ¥99，还差 ¥1。每次邀请以概率 p 获得 δ 元有效助力，否则为 0。单次助力独立，最多邀请 N 次。

r = ⌈1 / δ⌉

达到 r 次有效助力才算成功。进度金额只是虚拟进度；实际提现 X 只取 0 或 100 元。

02

成功率是二项分布的尾部

K ∼ Bin(N, p)
q = P(K ≥ r)

单次助力只有有效 / 无效两种结果（伯努利试验）。在独立且 p 不变的假设下，N 次中的有效次数 K 服从二项分布。将 K = r 到 N 的概率相加，就得到 q。

q = Σk=r…N C(N,k) pk(1−p)N−k

C(N,k) 表示从 N 次中选出 k 次有效位置的组合数。若 r > N，成功率就是 0。虽然模拟达标后会停止，“N 次内达标”和“预先生成 N 次结果后 K ≥ r”是等价事件。

允许无限次邀请时，达到 r 次有效助力所需的邀请总次数 T 服从负二项分布：E[T] = r/p，Var(T) = r(1−p)/p²（p > 0）。这里的期望不受 N 限制。

03

提现的期望与波动

E[X] = 100q
Var(X) = 100²q(1−q)

因为 X 以概率 q 取 100，以概率 1−q 取 0，所以 E[X] = 100×q + 0×(1−q)。再由 Var(X) = E[X²]−E[X]²，得到 10000q−10000q²。

期望是大量独立玩家的平均，不是你这一局会收到的钱。方差单位为元²，越大代表玩家结果的离散程度越高。

05 / 带着问题离开

如果一万个人都失败，
成功概率就是零吗？

先预测，再模拟，最后解释。点击问题，展开课堂提示。

没有一次成功，能证明不可能吗？

不能。若 n 次独立同分布实验观察到 0 次成功，成功率的单侧 95% 精确上界为 1−0.05^(1/n)，大样本时约为 3/n。小概率事件需要更大的样本量。

为什么 99% 的进度不等于 99% 的成功率？

进度是当前状态，成功概率还依赖后续规则、剩余次数与每次有效助力的概率。本模型初始进度一直为 99%，但调整 p、δ、N，成功概率可以截然不同。

如何研究平台的真实概率？

需要记录版本规则、玩家资格、每次助力、剩余时间与所有失败样本；按用户类型分层，避免只统计分享成功的玩家。若概率随进度或用户变化，独立同分布假设就不适用。
